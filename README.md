# Jarvis-BCA-final-year-Project

🧠 Project Title:
"J.A.R.V.I.S – A Voice-Controlled AI Assistant using Python"

✅ Project Objectives:
Build a desktop voice assistant that can perform basic tasks.

Use speech recognition and text-to-speech for interaction.

Execute commands like opening apps, fetching the time/date, web searches, playing music, etc.

🛠 Technologies Used:
Python 3.x

Libraries:
speech_recognition
pyttsx3
datetime
webbrowser
os
wikipedia
